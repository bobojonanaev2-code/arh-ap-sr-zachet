### 1. Ознакомление с файловой структурой ОС Linux и командами работы с файлами

Перед выполнением практических заданий была изучена иерархическая структура файловой системы Linux. Корневой каталог `/` содержит основные системные каталоги:

- `/bin` – выполняемые команды;
- `/tmp` – временные файлы;
- `/usr` – пользовательские программы и данные;
- `/etc` – конфигурационные файлы;
- `/dev` – специальные файлы устройств.

Для навигации использовались команды `pwd` (показать текущий каталог) и `cd` (сменить каталог). Текущим пользователем в системе является `bobojon`.

5. Полная информация о файлах и анализ прав доступа
Вывели подробную информацию о файлах в каталоге bobojon_lab:

bash
ls -l bobojon_lab/
Вывод (пример):

text
-rw-rw-r-- 1 bobojon bobojon 42 июн 22 10:15 bobojon1.txt
-rw-rw-r-- 1 bobojon bobojon 47 июн 22 10:16 bobojon2.txt
-rw-rw-r-- 1 bobojon bobojon 89 июн 22 10:17 bobojon_merged.txt
Анализ прав доступа:

Первый символ - означает обычный файл (не каталог).

Следующие три символа rw- – права владельца (чтение и запись, выполнение запрещено).

Следующие три rw- – права группы (чтение и запись).

Последние три r-- – права остальных пользователей (только чтение).

Таким образом, все файлы доступны для чтения и записи владельцу и группе, остальные могут только читать.

6. Добавление права выполнения для группы и остальных пользователей
Используем команду chmod в символьном режиме для добавления права выполнения (+x) для группы (g) и остальных (o):

bash
chmod g+x,o+x bobojon_lab/bobojon1.txt bobojon_lab/bobojon2.txt bobojon_lab/bobojon_merged.txt
Можно также применить ко всем файлам в каталоге:

bash
chmod g+x,o+x bobojon_lab/*
7. Просмотр изменённых атрибутов файлов
Проверим новые права:

bash
ls -l bobojon_lab/
Вывод:

text

-rwxrwxr-x 1 bobojon bobojon 47 июн 22 10:16 bobojon2.txt
-rwxrwxr-x 1 bobojon bobojon 89 июн 22 10:17 bobojon_merged.txt
Теперь у всех файлов для группы и остальных появился флаг x, что разрешает выполнение (для текстовых файлов это не имеет смысла, но демонстрирует изменение прав).

Контрольные вопросы
1. Что считается файлами в ОС Linux?
В Linux файлами считаются не только обычные файлы с данными, но и каталоги, а также специальные файлы устройств (блочные и символьные), символические ссылки, сокеты и именованные каналы. Все объекты файловой системы представлены в виде файлов, что обеспечивает единообразный интерфейс доступа.

2. Объясните назначение связей с файлами и способы их создания.
Связи (links) позволяют одному физическому файлу иметь несколько имён в файловой системе. Различают жёсткие и символические связи.

Жёсткая связь (ln) – создаёт дополнительное имя для существующего файла. Все жёсткие ссылки указывают на один и тот же индексный дескриптор (inode). Удаление файла происходит только после удаления всех ссылок.

Символическая связь (ln -s) – это отдельный файл, содержащий путь к целевому файлу. При обращении к ссылке система переходит по указанному пути. Символическая ссылка может указывать на файлы на других разделах и даже на несуществующие файлы.

3. Что определяет атрибуты файлов и каким образом их можно просмотреть и изменить?
Атрибуты файла определяют тип файла, права доступа (чтение, запись, выполнение) для владельца, группы и остальных, а также владельца и группу файла. Просмотреть атрибуты можно командой ls -l. Изменить права доступа – командой chmod, владельца – chown, группу – chgrp.

4. Какие методы создания и удаления файлов, каталогов Вы знаете?
Создание файлов:

touch file – создать пустой файл или обновить время доступа.

echo "текст" > file – создать файл с содержимым.

cat > file – создать файл, вводя текст с клавиатуры (завершить Ctrl+D).

Редакторы (nano, vim и др.).

Удаление файлов:

rm file – удалить файл.

rm -r dir – рекурсивно удалить каталог.

rmdir dir – удалить пустой каталог.

Создание каталогов:

mkdir dir – создать каталог.

mkdir -p path/to/dir – создать каталог со всеми промежуточными уровнями.

Удаление каталогов:

rmdir dir – удалить пустой каталог.

rm -rf dir – принудительно удалить каталог со всем содержимым.

5. В чем заключается поиск по шаблону?
Поиск по шаблону (pattern matching) – это поиск строк в текстовых файлах, соответствующих заданному регулярному выражению или простой строке. Для этого используется команда grep. Например, grep "bobojon" *.txt найдёт все строки, содержащие слово "bobojon", в файлах с расширением .txt. Ключи позволяют изменить поведение поиска (игнорировать регистр, выводить номера строк и т.д.).

6. Какой командой можно получить список работающих пользователей и сохранить его в файле?
Список работающих пользователей можно получить командой who или users. Чтобы сохранить результат в файл, используется перенаправление вывода:

bash
who > users_list.txt
или

bash
users > users_list.txt
