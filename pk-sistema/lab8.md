# Практическая работа № 8
## Тестирование персонального компьютера с помощью утилиты Passmark Performance Test

**Цель:** Провести финальное тестирование стабильности системы для последующей разработки технического задания по внедрению компьютерной системы.

---

## Теоретические сведения

**PerformanceTest** - набор тестов, позволяющих оценить общую производительность вашего ПК по сравнению с другими компьютерами. В программу входят двадцать семь стандартных тестов в семи группах, плюс еще пять для пользовательских тестов.

---

## Порядок выполнения работы

### 1. Виды тестов в Performance Test

В программе Performance Test есть 6 видов тестов:
- **PassMark** (общий рейтинг)
- **CPUmark** (9 подвидов)
- **2D Mark** (7 подвидов)
- **3D Mark** (4 подвида)
- **Memory Mark** (6 подвидов)
- **Disk Mark** (5 подвидов)

## Ответы на вопросы

### 1. Для каких целей может быть использована тестируемая компьютерная система?

Данная компьютерная система может быть использована для:
- **Офисных задач**: работа с текстовыми документами, таблицами, презентациями
- **Веб-серфинга**: просмотр сайтов, работа с электронной почтой
- **Просмотра мультимедиа**: воспроизведение видео и аудио контента
- **Обучения**: работа с образовательными программами и материалами
- **Базовой работы с файлами**: хранение и обработка документов

**Не рекомендуется для:**
- Игр и 3D-моделирования (низкая производительность графики)
- Профессиональной обработки видео
- Сложных инженерных расчетов

---

### 2. Какие параметры компьютерной системы можно было бы улучшить?

**Приоритетные улучшения:**

1. **Видеоадаптер (GPU)** - **КРИТИЧЕСКИ**
   - Текущий показатель: 229 (16-й процентиль)
   - **Рекомендация**: Установка дискретной видеокарты (NVIDIA GTX 1650 или выше)
   - Ожидаемый прирост: в 10-20 раз

2. **Дисковая подсистема**
   - Текущий показатель: 785 (41-й процентиль)
   - **Рекомендация**: Замена HDD на SSD NVMe
   - Ожидаемый прирост: в 5-10 раз

3. **Оперативная память**
   - Текущий показатель: 1239 (36-й процентиль)
   - **Рекомендация**: Увеличение объема ОЗУ до 16 ГБ и использование двухканального режима
   - Ожидаемый прирост: в 2-3 раза

4. **Процессор**
   - Текущий показатель: 4360 (40-й процентиль)
   - **Рекомендация**: Замена на современный процессор (Intel Core i5 12-го поколения или AMD Ryzen 5 5000 серии)
