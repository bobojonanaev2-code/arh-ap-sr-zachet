## Исходные данные

| Параметр | Значение |
|---|---|
| Заказчик | ООО «Ай-Теко» |
| Исполнитель | Специалист по внедрению |
| Система | Система контроля прохода на КПП |
| Условное обозначение | СКП |
| Основание | Необходимость повысить безопасность и автоматизировать учет проходов |

## Назначение системы

Система предназначена для контроля прохода сотрудников и посетителей через контрольно-пропускной пункт. Она должна фиксировать события доступа, хранить журналы и снижать вероятность несанкционированного прохода.

## Требования к системе

| Категория | Требование |
|---|---|
| Производительность | Быстрая регистрация прохода без задержек очереди |
| Надежность | Стабильная работа оборудования в течение рабочего дня |
| Безопасность | Авторизация по пропускам, защита журнала событий |
| Хранение данных | Сохранение логов не менее 12 месяцев |
| Обслуживание | Возможность резервного копирования и восстановления |

## Состав работ

1. Обследование места установки.
2. Подготовка оборудования и программного обеспечения.
3. Монтаж считывателей и рабочих мест.
4. Настройка учетных записей и прав доступа.
5. Проверка корректности фиксации проходов.
6. Обучение ответственных сотрудников.
7. Оформление акта ввода в эксплуатацию.

## Контроль и приемка

Приемка выполняется после тестирования основных сценариев: проход по действующему пропуску, отказ при недействующем пропуске, запись события в журнал, выгрузка отчета и восстановление данных из резервной копии.

## Вывод

В ходе работы подготовлена структура технического задания для внедрения системы контроля прохода. Документ фиксирует требования, этапы работ и критерии приемки.
