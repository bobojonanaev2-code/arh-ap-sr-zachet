# Лабораторная работа №2

## Тема

Работа с командной строкой Linux и подключение по SSH.

## Цель работы

Получить практические навыки подключения к удаленной системе, создания файловой структуры и настройки доступа по SSH-ключу.

## Ход работы

### 1. Подключение к удаленной системе

Для подключения к Raspberry Pi использовалась команда:

```bash
ssh user@192.168.129.150
```

После ввода пароля открывается терминальная сессия удаленной системы.

### 2. Создание структуры каталогов

В рабочем каталоге была создана папка с фамилией студента и вложенные файлы по заданию.

```bash
mkdir Anaev
cd Anaev
mkdir lab2 docs files
touch docs/report.txt files/test.txt
ls -R
```

Результат проверки структуры:

![Результат команды ls -R](img/lab2_1.png)

### 3. Настройка SSH-ключей

Сначала проверяется наличие уже созданных ключей:

```bash
ls ~/.ssh
```

Если ключей нет, создается новая пара:

```bash
ssh-keygen
```

Публичный ключ копируется на удаленную систему:

```bash
ssh-copy-id user@192.168.129.150
```

После этого подключение можно выполнять без ручного ввода пароля:

![Копирование SSH-ключа](img/lab2_2.png)

## Ответы на контрольные вопросы

### Что такое командная строка?

Командная строка - это текстовый интерфейс управления операционной системой. Пользователь вводит команды вручную, а командный интерпретатор выполняет их и выводит результат.

### Основные команды для работы с файлами

| Команда | Назначение |
|---|---|
| `ls` | Просмотр файлов и папок |
| `cd` | Переход в каталог |
| `pwd` | Вывод текущего пути |
| `mkdir` | Создание папки |
| `touch` | Создание файла |
| `cp` | Копирование |
| `mv` | Перемещение или переименование |
| `rm` | Удаление |
| `cat` | Просмотр содержимого файла |

### Команды для получения информации о системе

```bash
uname -a
hostname
whoami
df -h
free -h
ip a
ps aux
```

### Можно ли управлять системой только через командную строку?

Да. Через командную строку можно устанавливать программы, управлять пользователями, настраивать сеть, работать с файлами, запускать службы и выполнять администрирование удаленных серверов.
