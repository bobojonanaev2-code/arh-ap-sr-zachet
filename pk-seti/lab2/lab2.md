## Ход выполнения работы

### 1. Подключение по SSH

Для подключения к удаленной системе используется команда:

```bash
ssh user@192.168.129.150
```

После ввода пароля открывается терминальная сессия, в которой можно выполнять команды Linux.

### 2. Создание структуры каталогов

В рабочем каталоге была создана папка студента и вложенные директории по заданию.

Пример команд:

```bash
mkdir Anaev
cd Anaev
mkdir lab2 docs files
touch docs/report.txt files/test.txt
ls -R
```

Команда `ls -R` выводит структуру созданных каталогов и файлов.

### 3. Проверка наличия SSH-ключей

Перед настройкой входа по ключу проверяется папка `.ssh`:

```bash
ls ~/.ssh
```

Если ключи отсутствуют, создается новая пара:

```bash
ssh-keygen
```

### 4. Копирование открытого ключа

Открытый ключ копируется на удаленную систему командой:

```bash
ssh-copy-id user@192.168.129.150
```

После этого подключение можно выполнять без постоянного ввода пароля, если ключ корректно добавлен на сервер.

## Ответы на контрольные вопросы

### 1. Что такое командная строка?

Командная строка - это текстовый интерфейс для управления операционной системой. Пользователь вводит команды, а командный интерпретатор выполняет их и выводит результат.

### 2. Основные команды для работы с файлами и каталогами

| Команда | Описание | Пример |
|---|---|---|
| `ls` | Просмотр файлов и папок | `ls -la` |
| `cd` | Переход в каталог | `cd /home/user` |
| `pwd` | Вывод текущего пути | `pwd` |
| `mkdir` | Создание папки | `mkdir lab` |
| `touch` | Создание файла | `touch file.txt` |
| `cp` | Копирование | `cp a.txt b.txt` |
| `mv` | Перемещение или переименование | `mv old.txt new.txt` |
| `rm` | Удаление | `rm file.txt` |
| `cat` | Просмотр содержимого файла | `cat file.txt` |

### 3. Команды для вывода информации о системе

| Команда | Назначение |
|---|---|
| `uname -a` | Информация о ядре и системе |
| `hostname` | Имя устройства |
| `whoami` | Текущий пользователь |
| `date` | Дата и время |
| `free -h` | Информация об оперативной памяти |
| `df -h` | Информация о дисках |
| `ip a` | Сетевые интерфейсы и IP-адреса |
| `ps aux` | Список процессов |

### 4. Команды ввода и вывода данных из файлов

| Команда | Назначение |
|---|---|
| `cat file` | Вывести содержимое файла |
| `less file` | Постраничный просмотр |
| `head file` | Показать первые строки |
| `tail file` | Показать последние строки |
| `echo "text" > file` | Записать текст в файл с перезаписью |
| `echo "text" >> file` | Добавить текст в конец файла |
| `grep "text" file` | Найти строку в файле |
| `wc file` | Подсчитать строки, слова и символы |

### 5. Можно ли управлять системой только через командную строку?

Да. Через командную строку можно устанавливать программы, управлять пользователями, настраивать сеть, работать с файлами, запускать службы и выполнять удаленное администрирование по SSH.

### 6. Чем Windows CMD отличается от MS-DOS?

MS-DOS является самостоятельной старой операционной системой, а CMD - это командная оболочка внутри Windows. CMD работает поверх Windows API, поддерживает многозадачность системы и может использовать современные сетевые возможности Windows.

### 7. Какие командные интерпретаторы применяются в разных ОС?

| Операционная система | Интерпретаторы |
|---|---|
| Linux | `bash`, `zsh`, `fish`, `sh` |
| macOS | `zsh`, `bash` |
| Windows | `cmd`, `PowerShell`, Windows Terminal |
| BSD | `sh`, `tcsh`, `csh` |
