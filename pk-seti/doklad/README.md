# Доклад: IP, MAC и DNS

## Введение

Для обмена данными в сети устройствам нужны разные виды адресов. На практике чаще всего встречаются MAC-адрес, IP-адрес и доменное имя, которое обрабатывается системой DNS.

## MAC-адрес

MAC-адрес - это аппаратный идентификатор сетевого интерфейса. Он используется на канальном уровне и помогает доставлять кадры внутри локальной сети.

Пример записи:

```text
00:1A:2B:3C:4D:5E
```

## IP-адрес

IP-адрес - это логический сетевой адрес. Он нужен для маршрутизации пакетов между сетями.

Существуют два основных формата:

- IPv4: `192.168.1.10`
- IPv6: `2001:db8::1`

## DNS

DNS преобразует доменные имена в IP-адреса. Пользователь вводит понятный адрес сайта, например `example.com`, а компьютер получает IP-адрес сервера и устанавливает соединение.

## Сравнение

| Параметр | MAC | IP | DNS |
|---|---|---|---|
| Уровень работы | Канальный | Сетевой | Прикладной |
| Назначение | Доставка внутри локальной сети | Маршрутизация между сетями | Преобразование имени в IP |
| Пример | `00:1A:2B:3C:4D:5E` | `192.168.1.10` | `github.com` |
| Изменяемость | Обычно постоянный | Может меняться | Меняется через настройки домена |

## Вывод

MAC-адрес, IP-адрес и DNS решают разные задачи. MAC используется внутри локальной сети, IP отвечает за маршрутизацию, а DNS делает работу с интернетом удобной для человека.
